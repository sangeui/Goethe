# 업무일지 작성 워크플로

에이전트는 작업 단위가 끝나고 사용자의 지시나 동의를 얻게 되면, 다음 순서에 따라 업무일지를 정확하게 기록합니다.

1. **디렉토리 생성**: 현재 시스템 날짜 기준 `YYYY-MM` 폴더가 `.agents/logs/` 내에 존재하는지 확인하고, 없다면 생성합니다.
2. **파일 스캔**: 오늘 날짜를 기준으로 `.agents/logs/YYYY-MM/YYYY-MM-DD.md` 파일이 존재하는지 읽어옵니다(`view_file` 활용).
3. **최초 생성 (파일이 없을 시)**: `.agents/logs/_TEMPLATE.md`에 맞춰 파일을 생성하고, 첫 번째 작업 블록을 추가합니다 (`write_to_file` 활용).
4. **추가 기록 (파일이 존재할 시)**: 기존 내용을 보존한 상태에서, 문서 맨 하단에 `## [HH:MM] 작업_요약` 형식의 마크다운 블록을 새로 합쳐 문서 내용을 통째로 업데이트합니다 (`replace_file_content` 또는 `write_to_file` 오버라이드 활용).
5. **보고**: 기록이 성공적으로 추가되었음을 사용자에게 파일 경로와 함께 1~2줄로 짧게 통보합니다.
