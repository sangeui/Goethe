# 자동 커밋 대리인 매뉴얼 (/commit-work)

이 워크플로는 사용자가 귀찮은 터미널 타이핑을 하지 않아도 003번 로컬 룰을 100% 정확하게 준수하며(영문 혼용 방지 등) 에이전트가 스스로 `git commit`을 찍도록 만드는 매크로 장치입니다.

1. 무조건 `run_command` 도구를 사용하여 터미널에서 `git status`를 먼저 실행하고, 수정되거나 추가된 파일들의 목록과 상태를 읽어들인다.
2. `003-git-convention.md` 룰을 시스템 메모리에 로드한 뒤, 현재 변경 사항을 기반으로 가장 알맞은 1개의 타입(예: `feat`, `fix`, `docs` 등)과 **100% 한국어 명령형 제목**, 그리고 변경 맥락(Why)이 담긴 서술형 본문을 임시 작성한다. (영어 단어 사용 시 역적 행위로 간주함).
   * **[필수 지정]** 에이전트가 대행했음을 명시하기 위해, 커밋 본문의 가장 마지막 줄에 무조건 한 줄을 띄우고 `> 🤖 Antigravity 에이전트에 의해 자동 커밋됨` 이라는 시그니처를 고정으로 덧붙여라.
3. 임시 작성한 커밋 메시지를 사용자에게 미리보여주며 컨펌받을 필요 없이(사용자가 이미 승인했으므로), 즉각적으로 `run_command` 도구를 실행해 `git add .` 및 `git commit -m "타입(스코프): 제목...본문..."` 명령어를 타격하라.
4. 명령어가 성공적으로 완료되면 사용자에게 완성된 커밋 내역을 마크다운 표로 깔끔하게 브리핑한다.
5. 브리핑이 끝난 즉시, 예외 없이 다음 룰 톱니바퀴로 연결되도록 아래 멘트를 날려라: *"이 커밋 내역을 오늘자 업무일지(/log-work)에도 바로 누적 기록할까요?"*
6. **[무한루프 방지 어멘드 락]**: 사용자가 승낙하여 업무일지(`.agents/logs/`) 파일을 갱신하게 되면, `git status` 상에 '업무일지 수정본'이 커밋되지 않은 찌꺼기로 남게 된다. 이를 방지하기 위해 로깅 작업 직후 에이전트는 몰래 터미널 도구를 구동하여 `git add .` 및 `git commit --amend --no-edit` 백그라운드 명령어를 타격하여 방금 전 커밋 속에 추가 찌꺼기를 완벽히 먹어 치워야(Swallow) 한다.
