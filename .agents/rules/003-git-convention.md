# Git Commit Convention Rule
> [!CAUTION]
> 절대 룰: 모든 Git 커밋 메시지(제목 및 본문)는 **일체의 영어를 허용하지 않으며 100% 한국어**로만 작성해야 함.

## 1. 정형 구조 강제 (에이전트 적용 의무)
타입(옵셔널 스코프): 한글로 작성한 요약 제목
(한 줄 띄우기 필수)
- [본문] 무엇을, 어떤 맥락으로, 왜(Why) 수정/추가했는지 불릿 포인트로 상세 작성.
- (어떻게 코드를 짰는지는 코드를 보면 알 수 있으므로 적지 말 것)

## 2. 허용 타입 (Type)
에이전트가 `--message` 옵션으로 커밋할 때는 반드시 아래 7개 접두사 중 1개를 골라야 함:
* `feat`: 새로운 기능 구현
* `fix`: 버그/오류 논리 픽스
* `refactor`: 의미/로직 변경 없이 코드 리팩토링
* `style`: 가독성, UI 포맷, 세미콜론 수정 등
* `docs`: 리드미(README) 혹은 `.agents/` 마크다운 문서 등 수정
* `test`: 테스트 코드/Mock 데이터 추가
* `chore`: 빌드 스크립트, 의존성 설치(npm) 등 잡무

## 3. 쓰레기 커밋 생성 엄벌
- "업데이트", "내용 수정됨", "WIP" 같은 내용 없는 쓰레기 커밋 절대 금지. 모든 커밋 본문은 향후 릴리스 노트로 쓰일 수 있는 전문성을 띄어야 한다.
