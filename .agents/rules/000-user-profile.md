# User Profile (Default: Antigravity System Thinker Boilerplate)
1. System Thinker: 단기 코딩보다 영구적인 원칙/SOP(워크플로) 구축 최우선.
2. Strict Rules: 예외 없는 무조건적인 실행 준수. '죽은 기능' 엄금.
3. Modular Data: AI 탐색 최적화(단일 문서 지양, 분할 관리) 선호.

> [!CAUTION]
> 절대 원칙: 사용자 성향 추가 파악 시, 즉시 "프로파일에 업데이트할까요?" 제안 후 승인 시 본 문서 갱신.
