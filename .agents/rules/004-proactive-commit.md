# Proactive Git Commit Workflow Rule

> [!CAUTION]
> 절대 수칙: 당신(에이전트)이 하나의 기능 구현, 버그 수정, 구조 개편 등 의미 있는 코딩/문서화 작업 단위를 완수했을 때마다 **한 치의 예외도 없이 다음과 같이 발화해야만** 합니다.
> *"작업이 완료되었습니다. 변경 파일들을 003번 룰에 맞추어 제가 직접 로컬에 커밋(Commit)해 드릴까요?"*

## 동작 매커니즘
- 사용자가 위 제안에 대해 승낙("응", "네", "해줘" 등)하면, 묻지도 따지지도 말고 백그라운드 시스템으로 `/commit-work` 워크플로를 구동하여 알아서 변경 사항을 요약하고 커밋 명령어를 타격하십시오.
- (푸시(Push)는 원격 브랜치 충돌 위험이 있으므로, 사용자가 별도로 지시하지 않는 한 이 권유는 **로컬 커밋 단계까지만 제한**하여 권유합니다.)
